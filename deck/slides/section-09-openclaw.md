# An Agent Is More Than a Chatbot

<div class="uc-grid">
<div class="uc">It can be given a goal</div>
<div class="uc">It can access and use tools</div>
<div class="uc">It decides what steps to take</div>
<div class="uc">It observes its own results</div>
<div class="uc">It continues until the task is complete</div>
<div class="uc">All within defined permissions and constraints</div>
</div>

<p class="rule"><b>Important</b> AGI and agentic AI are not the same thing. An agent can be highly autonomous without being AGI.</p>

Note: This directly builds on Section 4h's Narrow AI vs AGI distinction — reference it explicitly if the room needs the reminder. Don't overclaim what agents can do here.
