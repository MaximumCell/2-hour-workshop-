<div class="lesson-no">Section 4 · Core concept</div>

# Bad prompt = bad result.<br/>Good prompt = <u>good</u> result.

The model didn't get worse. Your instructions did all the work — and vague instructions always produce vague output.

Note: Set up the whole section on this one idea. Don't rush it, let it land before showing the weak example.

---

<div class="lesson-no">Section 4 · Example</div>

# A weak prompt

<div class="codecard">
<div class="cc-bar"><span class="cc-dot r"></span><span class="cc-dot y"></span><span class="cc-dot g"></span><span class="cc-label">Weak Prompt</span></div>

```
Role: you are a world class expert youtube hook writer
Context: rewrite my hook, make it more better and attention grabbing
Be creative
```

</div>

Vague role. No real context. No format. No constraints — so the model guesses, and guesses safely.

Note: Read the weak prompt aloud in a flat, generic tone to sell the point. This is the "before" — the meta-prompt on the next slide is the fix.

<div class="lesson-no">Section 4 · The hack</div>

# The meta-prompt

<div class="codecard">
<div class="cc-bar"><span class="cc-dot r"></span><span class="cc-dot y"></span><span class="cc-dot g"></span><span class="cc-label">Copy This</span></div>

```
Role: Act as an elite Prompt Engineering Consultant.

Objective: Transform any prompt I provide into a high-performance
prompt that maximizes clarity, accuracy, relevance, and output
quality from AI models.

Process: Understand the original intent. Remove ambiguity and
unnecessary wording. Add missing context where beneficial. Improve
structure and readability. Optimize instructions, constraints, and
output format. Preserve the original meaning and goal.

Deliverables:
1. Optimized Prompt
2. Rationale for Changes
3. Optional Advanced Version (if further optimization is possible)

Original Prompt: {PASTE_PROMPT_HERE}
```

</div>

<span class="demo">Live demo</span>

Note: This is the single most copy-pasted slide of the whole workshop. Give students a moment to actually copy it before running the live demo. Pin this slide, or repeat the prompt in chat.
